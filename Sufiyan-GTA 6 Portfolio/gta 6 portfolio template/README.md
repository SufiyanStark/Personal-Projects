# 🌴 GTA 6 / VICE CITY CINEMATIC PORTFOLIO TEMPLATE

Welcome to the **GTA 6 / Vice City Cinematic Scroll Portfolio Template**! This template features a dual HTML5 canvas background scrub engine, GSAP ScrollTrigger timeline animations, Lenis smooth scrolling physics, clamped 3D perspective card tilt, and Vice City synthwave aesthetics.

---

## 📁 Template Folder Structure

```
template/
├── index.html                # Clean HTML structure with customizable placeholders
├── style.css                 # Vice City neon glassmorphism stylesheet
├── main.js                   # Dual canvas sequence scroll engine & GSAP animations
├── README.md                 # Complete template documentation
├── QUICKSTART.md             # 3-Step Quickstart Guide
├── PROMPTS.md                # AI Prompts for Antigravity / Claude / ChatGPT
├── scripts/
│   └── extract_sequences.py  # Automation script to extract & process user videos
└── assets/
    ├── images/               # Replace image1.png, image2.jpg, image3.png, image4.png
    ├── sequence/             # Background sequence 1 WebP frames
    └── sequence2/            # Background sequence 2 WebP frames
```

## 🛠️ Features Included

1. **Dual Canvas Frame Sequence Engine**:
   - Smoothly scrubs WebP frame sequences synced to scroll position.
   - Dual-sequence transition at **`LET'S BUILD TOGETHER`** with scanline flash FX!

2. **Vice City Neon Glassmorphism UIs**:
   - Frosted glass panels (`backdrop-filter: blur(16px)`).
   - Neon cyan (`#31e6ff`) and magenta (`#ff2f9e`) hover glows.

3. **Clamped 3D Card Tilt**:
   - Interactive mouse tilt capped to a subtle $\pm 5^\circ$ angle (`[data-tilt]`).

4. **Custom Vice City Neon Cursor**:
   - Custom crosshair follower with cyan/magenta pulse state on interactive links.
