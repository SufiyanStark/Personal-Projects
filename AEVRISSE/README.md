# AEVRISSE

### Interactive Luxury E-Commerce Experience

AEVRISSE is an experimental frontend e-commerce experience designed to explore how modern web technologies can create a more immersive way of browsing and interacting with products.

Instead of presenting products through a traditional static storefront, AEVRISSE uses scroll-driven transitions, interactive product experiences, and a boutique-inspired interface to create a more cinematic shopping journey.

---

## Overview

The experience begins outside the AEVRISSE storefront and transitions into an interactive boutique as the user scrolls.

The project focuses on combining:

- Modern frontend architecture
- Scroll-driven interactions
- Interactive product presentation
- Responsive UI design
- Product inspection experiences
- Shopping bag state management
- Reusable component architecture

The project was built as a personal frontend engineering project to experiment with interactive e-commerce interfaces and modern AI-assisted development workflows.

## Features

### Interactive Storefront

The experience begins with an exterior storefront and uses scrolling to transition the user toward the boutique interior.

### Scroll-Driven Experience

Scrolling controls parts of the visual experience rather than simply moving through traditional page sections.

### Boutique Interior

The interface transitions from the exterior storefront into a luxury boutique environment designed around product discovery.

### Product Experience

Products are represented through reusable product architecture, allowing product information and interactions to be managed consistently.

### Product Inspection

Users can enter a focused product inspection experience to view and interact with individual products.

### Shopping Bag

Products can be added to a shopping bag through shared application state.

### Responsive Interface

The interface is designed to adapt across different viewport sizes while maintaining the intended visual experience.

## Architecture

The application is structured around reusable React components and centralized product data.

Major areas of the project include:

```text
AEVRISSE
│
├── Storefront Experience
│
├── Scroll Experience
│
├── Boutique Interior
│   ├── Clothing Section
│   └── Product Displays
│
├── Product Experience
│   ├── Product Data
│   ├── Product Inspection
│   └── Shopping Bag State
│
└── Responsive UI
```

This structure keeps visual presentation, product information, and interaction logic separated and easier to extend.

## Getting Started

### Prerequisites

Make sure you have Node.js and pnpm installed.

Check your versions:

```bash
node --version
pnpm --version
```

### Clone the Repository

```bash
git clone <YOUR-REPOSITORY-URL>
```

Navigate to the AEVRISSE project:

```bash
cd <AEVRISSE-PROJECT-FOLDER>
```

Install dependencies:

```bash
pnpm install
```

Start the development server:

```bash
pnpm dev
```

Open:

```text
http://localhost:3000
```

in your browser.
